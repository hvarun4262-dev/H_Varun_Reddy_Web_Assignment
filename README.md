# H Varun Reddy — Resume & Bio-Data Website

## Assignment
Construct a website (multiple web pages) containing resume and bio-data by using relevant HTML elements and appropriate styling for presentation with CSS/jQuery/JavaScript. Host the website on a cloud platform.

## Pages
- index.html — Home / profile
- resume.html — Resume
- biodata.html — Bio-Data
- contact.html — Contact + jQuery validation

## Technologies
HTML5, CSS3, JavaScript, jQuery 3.7.1 (CDN)

## Interactive Features
- Active navigation highlighting
- Smooth scrolling
- Automatic current year
- Contact-form validation with jQuery
- Bio-data declaration show/hide
- Resume print / Save as PDF

## GitHub Pages Hosting
1. Create a GitHub repository, e.g. `varun-resume-biodata`.
2. Upload all files in this folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. GitHub will provide the public Pages URL.

Before submission, replace `Your College Name`, `Junior College Name`, `School Name`, and the permanent-address placeholder with your actual details.
